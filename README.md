# Stika Notes

Sticky notes that look like paper and stay on the desktop you put them on. For Mac and Windows.

**More about it:** [kidwaarif.com/side-quests/stika-notes](https://kidwaarif.com/side-quests/stika-notes)

## Download 0.3.6

- **Mac** (Apple Silicon and Intel, macOS 13+): [Stika-Notes-0.3.6-mac.dmg](downloads/Stika-Notes-0.3.6-mac.dmg) · 10.3 MB
- **Windows** (10 and 11): [Stika-Notes-0.3.6-windows-setup.exe](downloads/Stika-Notes-0.3.6-windows-setup.exe) · 4.0 MB

The first time you open it, macOS or Windows asks you to confirm, because the app isn't signed with a paid certificate yet. After that, Stika Notes updates itself from inside the app.
