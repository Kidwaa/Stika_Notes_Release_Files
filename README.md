# Stika Notes

Sticky notes that look like paper and stay on the desktop you put them on. For Mac and Windows.

**More about it:** [kidwaarif.com/side-quests/stika-notes](https://kidwaarif.com/side-quests/stika-notes)

## Download 0.3.2

- **Mac** (Apple Silicon and Intel, macOS 13+): [Stika-Notes-0.3.2-mac.dmg](downloads/Stika-Notes-0.3.2-mac.dmg) · 7.4 MB
- **Windows** (10 and 11): [Stika-Notes-0.3.2-windows-setup.exe](downloads/Stika-Notes-0.3.2-windows-setup.exe) · 3.1 MB

The first time you open it, macOS or Windows asks you to confirm, because the app isn't signed with a paid certificate yet. After that, Stika Notes updates itself from inside the app.

---

This repository only holds the installers and update files. `latest.json` tells the app and the website which version is newest; every update file is signed, and the app checks the signature before installing.
